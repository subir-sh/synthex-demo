# Synthex Demo

**[브라우저에서 플레이](https://subir-sh.github.io/synthex-demo/)**

불·물·흙 원소를 조합해 마법을 사용하는 로그라이크 카드 게임의 개발 중 데모입니다.

## 실행과 전체화면

첫 실행 시 약 44MB를 내려받습니다. 원본 일러스트는 보존하고 웹 버전의 이미지 데이터만 최적화했습니다.

PC 브라우저에서 링크를 열고, 로딩이 끝나면 **전체화면으로 플레이**를 누르세요. **Esc**를 누르면 전체화면에서 나옵니다. 창에서 플레이를 선택한 경우에도 화면 오른쪽 위의 **전체화면** 버튼으로 전환할 수 있습니다.

## 조작법

1. 메인 화면에서 **새 원정**으로 시작합니다. 저장된 원정은 **이어하기**로 계속할 수 있습니다.
2. 지도에서 연결된 다음 지점을 클릭합니다.
3. 손패의 원소를 **클릭해서 선택**합니다. 다시 클릭하면 선택이 해제됩니다.
4. 요구 원소를 맞추면 손패 위에 사용할 마법이 나타납니다. **마법을 클릭해 시전**하거나, 대상이 필요한 마법을 **적 또는 손패 원소로 드래그**하세요.
5. 행동을 마쳤으면 **턴 종료**를 누릅니다. 이후 적이 행동하고 다음 턴이 시작됩니다.
6. 전투 보상에서 스펠을 선택하고, 전투 사이에 마법서를 열어 장착할 스펠을 정합니다.

카드와 키워드에 마우스를 올리면 설명을 볼 수 있습니다. 긴 목록은 마우스 휠로 스크롤할 수 있습니다.
